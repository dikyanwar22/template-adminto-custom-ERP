Cara pakai (copy-paste)
  1. Buka file di library/ yang ingin dicontek.
  2. Copy blok yang dibutuhkan (misal #mainDatatable atau #calendar) atau copy seluruh file.
  3. Paste ke file baru — header/topnav/drawer sudah siap, edit hanya .main-content.
  4. Jika file di root sejajar ERP.html, ganti css/style.css ? library/css/style.css dan js/main.js ? library/js/main.js.
