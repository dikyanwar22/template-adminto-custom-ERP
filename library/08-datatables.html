Datatable — Cara Contek

Copy blok: <table id="mainDatatable"> + script di bawah <script>.

  • Ganti ajax dengan URL API kamu untuk server-side.
  • Untuk hapus export, hapus buttons: [...].
  • Untuk tambah kolom, tambah <th> + columns: [...] di JS.
$('#mainDatatable').DataTable({
  dom: 'Bfrtip',
  buttons: ['excel','pdf','print'],
  pageLength: 10,
  language: { search: "Cari:" }
});
